# pro-demos

Interactive HTML demos for PRO-spectus Salesforce work, hosted on GitHub Pages so Confluence (TD space) can embed them with the iframe macro. Synthetic or anonymised sandbox data only.

| Folder | Demo | Source of truth |
|---|---|---|
| `org-architecture/` | Org Architecture: who can see what today, the target model, and how a day changes | `prospectus-salesforce/docs/security/pro-access-model/demo/index.html` |
| `correspondence-letters/` | Beren correspondence (DocGen letters) | `Desktop/Correspondence-Letters-Demo-2026-11-06.html` |
| `product-replacement/` | Product replacement journey (TD-2280) | `prospectus-salesforce/docs/td-2280/product-replacement-journey-demo.html` |

Update a demo: copy the new file over `<folder>/index.html`, commit, push. The Confluence pages need no edit. CareTend lives in the separate `caretend-demo` repo.
